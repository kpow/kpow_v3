The test program

It uses only M5Stack's own libraries: M5Unified 0.2.29, M5GFX 0.2.36 and StackChan-BSP at commit 8d4d6fc. No WiFi, audio, LEDs or camera.

  • Head motion goes through M5StackChan.Motion.move() and nothing else. A new random pose every 3 seconds: yaw ±60°, pitch 15° to 50° above the BSP's default zero, speed 400.
  • Both servos are pinged every 500 ms. No reply to two pings in a row counts as a freeze.
  • During a freeze the program keeps sending moves. After 30 seconds it switches servo power off for 500 ms and on again.
  • Power is left as M5.begin() sets it (5 V output on) for the whole test.

The two shutdowns

  • After each one, AXP2101 register 0x21 (power-off source) read 0x08: system voltage (VSYS) under-voltage.
  • The base battery read 3.49 V (run 3) and 3.50 V (run 4) one second before, drawing 0.9 A. The charge level read 86% and 89% afterwards.
  • The run after each shutdown records it in its START row (off_src 08), and the waiting screen shows it as last shutdown: power chip: system voltage too low. Video 1 opens on that screen.
