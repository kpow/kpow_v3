What this option changes
  • Every entry is one row on the existing purple spine: date, title, tags, up to 3 tiny thumbs. Tap a row to open it in place.
  • Month markers sit on the spine (diamond node + count). The newest entry starts open; everything else is closed.
  • Expand all / Collapse all above the list. Each open entry has a link (#e-…) that opens it directly.
  • Photos: 1 = wide, 2 = side by side, 3+ = lead + two, with “+N more” on the last tile. Every tile opens the lightbox, which now steps through the entry (← →).
  • Videos show their poster with a play button instead of autoplaying (today every mp4 on the page autoplays, ~5 MB each).
  • Top switch: the same treatment on /builds/recently (139 entries) with build filter chips.
